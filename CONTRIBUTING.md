# Contributing

This project is a source-available development preview. Read LICENSE,
docs/LICENSING.md and SECURITY.md before sharing code or data.

Use dummy configuration and assets you have permission to distribute. Do not
include personal keys, chats, screenshots, recordings or downloaded models.
Run npm run build, npm test and npm run check:publish before proposing changes.

Retain third-party notices. Explain behavior changes and the tests performed;
distinguish automated checks from manual platform acceptance.

You retain ownership of your contributions. Opening a pull request does not
automatically transfer copyright or grant the maintainer commercial relicensing
rights. The maintainer must confirm sufficient licensing rights before merging
code intended for commercial relicensing; a separate agreement may be needed.
