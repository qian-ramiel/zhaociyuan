# 中英日界面语言

## 规则

- 全局设置顶部提供“界面语言”，可选择中文、English、日本語。保存成功后即时切换，不重新加载窗口。
- 新安装读取 macOS 的首选系统语言。中文地区与繁体语言代码统一使用当前简体中文界面，英语与日语地区代码归入各自语言；其他系统语言使用英文。
- 手动选择存入全局桌面配置，重启与切换角色后保留。旧用户没有语言字段时只初始化一次；已有手动选择不被系统语言覆盖。
- 网页预览首次根据浏览器语言选择；保存后的全局偏好优先。
- 控制面板、独立聊天、悬浮工具栏、状态栏菜单、窗口标题、时间格式与固定通知使用同一套词条。原生权限用途说明提供中英日资源，其展示语言仍由 macOS 决定。

## 内容边界

角色名称、人设、提示词、聊天、记忆、资源名称及自定义模式名称保持原文，存储内容不会因切换而改变。未修改的内置模式名称按界面语言显示；重命名后保持自定义名称。界面语言不改变语音识别设置、TTS 音色或模型回复语言。

运行记录中的原始服务诊断、供应商返回文本和模型输出保留原文，便于排查，不通过机器翻译改写；运行记录的筛选器、栏目、结果状态等界面文案已翻译。

## 实现

`apps/desktop/locale.mjs` 共享语言匹配、词条插值与无重挂载语言状态。`apps/desktop/locales/messages.json` 用原中文文案作为稳定键，英文和日文成对维护。React 使用外部状态订阅，Electron 持久化并广播给各窗口。没有对整个 DOM 文本进行替换，也不会把用户内容交给翻译接口。

`DesktopSettings.language` 允许 `zh`、`en`、`ja` 或尚未初始化的空值。旧客户端提交缺少语言字段的桌面配置时，已有手动偏好不会被清除。

## 验证

`npm test` 检查语言代码、英文回退、手动偏好优先、词条完整性、插值、原生菜单、跨窗广播、保存失败回滚及角色内容不变。

`npm run test:i18n` 使用隔离数据验证四种首次语言、中英日切换、草稿保留、重载持久化和各页面截图。`npm run test:feedback` 保留中文基线，验证原有语音、捕获、模式及工作流功能。

语言匹配测试通过注入首选系统语言和独立浏览器语言进行，不代替在不同语言的真实系统上逐项验收。macOS 的权限弹窗语言由系统决定，不保证随应用内语言立即切换。
