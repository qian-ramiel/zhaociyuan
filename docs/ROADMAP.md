# 路线图

## 当前：1.0 开发预览

桌面角色、配置、聊天、语音、授权屏幕观察和基本 macOS 打包已形成闭环。先用于私有预发布和进一步验收，不声称稳定或跨平台可用。

## 优先验证

- 不同 macOS / Apple Silicon 设备上的首次安装、权限授权、重启和退出。
- 真实麦克风、噪声和回声、插话打断、长时间通话。
- 游戏内快捷键、全屏与多桌面窗口行为、截图边界和视觉识别。
- 不同 LLM / TTS 厂商的流式协议、错误、超时、额度和取消行为。
- 密钥存储降级提示、资源导入安全与第三方依赖审查。
- 安装包的 Developer ID 签名、公证及第三方发行许可。

## 后续候选

Intel / Windows / Linux、VRM、系统音频、插件、节点式工作流、可选同步与更完整的角色生态。这些是方向，不是已经实现的功能或发布日期承诺。
