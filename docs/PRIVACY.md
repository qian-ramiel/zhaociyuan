# 隐私与数据边界

兆次元当前没有内置云端账号、广告或项目方聊天上传服务。使用第三方模型不等于离线运行：对话、检索到的记忆 / 知识片段、授权截图或待合成语音文本可能发送到你配置的服务地址。请先了解服务商的数据政策和价格。

## 本地保存

- 开发版数据默认在 `runtime/v1/`，导入资源和本地权重在 `resources/`。
- macOS 安装版使用 `~/Library/Application Support/Nice People/`；沿用旧目录以兼容既有数据。
- 密钥优先保存在系统钥匙串。钥匙串不可用时可能退回 `secrets.json`，它是明文文件，仅以文件权限限制访问，不是加密保险箱。
- 密钥不进入角色包或服务方案导出。用户主动导出的包仍可能包含私人设定、素材，以及用户选择携带的记忆或聊天，不应直接公开。
- 截图只在当前请求和有限的内存预览缓存中使用；切换角色、清空聊天或退出后移除。聊天历史保存截图来源和时间，不保存原始截图。
- 卸载应用不会自动删除数据或钥匙串中的密钥。

## 权限

麦克风、屏幕录制、辅助功能分别授权。屏幕观察还受全局开关、角色与陪伴模式规则控制。快捷键功能处理必要的按键事件，不保存键盘输入日志；不提供系统声音监听。

选择窗口仍可能捕获其中的私人内容。暂停观察或关闭视觉开关后，文字及语音消息不应再附带截图。请用实际系统权限和目标窗口验收此行为，不要只依赖 UI 状态。

## 诊断和分享

运行记录用于诊断服务阶段、错误码和请求状态，不以保存完整请求正文为目标。第三方错误、手动附加日志或截图仍可能含私人内容。提交前检查密钥、聊天、窗口名、邮箱和本机路径；不要上传数据库或完整运行目录。

本地服务只应监听回环地址，不应部署成公网服务。当前没有经过完整的独立安全审计。
