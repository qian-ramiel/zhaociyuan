# 兆次元 1.0.0-beta.1 · 私有测试版

首个附带安装包的私有测试 Release。仓库保持 Private，只有已获仓库读取权限的 GitHub 账号能查看和下载；遇到 404，请检查登录账号和邀请状态。本版不是稳定发行，勿公开转存。

## 下载与安装

下载本页附件 `Zhaociyuan-1.0.0-beta.1-mac-arm64.dmg`，打开后把“兆次元”拖入 Applications，再从“应用程序”启动。仅支持 **Apple Silicon（M 系列）Mac，macOS 13+**，不支持 Intel、Windows 或 Linux。

普通测试者无需安装 Node.js、Python 或 ffmpeg。内置 Kokoro TTS 和 SenseVoice ASR；没有私人角色、聊天、Key 或 LLM 额度，需要自行创建角色、导入有使用权的形象并配置模型。

- [详细安装说明](https://github.com/qian-ramiel/zhaociyuan/blob/v1.0.0-beta.1/docs/release/MAC-INSTALL.md)，也随 Release 作为 `MAC-INSTALL.md` 附件提供。
- `SHA256SUMS-beta.1.txt` 包含 DMG 的 SHA-256；下载到同一目录后运行 `shasum -a 256 -c SHA256SUMS-beta.1.txt` 验证，应显示 `OK`。

## 重要安全提示

当前只有 ad-hoc 完整性签名，**没有 Apple Developer ID 签名与公证**。确认下载来源与校验值后，可按安装说明在系统设置中查看“仍要打开”。若提示恶意软件、文件损坏或无法打开，请停止并反馈，不要全局关闭系统安全检查。本轮未验证真实网络下载的 Gatekeeper 隔离流程。

麦克风、屏幕录制和辅助功能分别授权；只使用文字聊天不需全部开启。屏幕观察还需要应用、角色和模式授权。请先用非敏感窗口测试。配置第三方服务后，必要的对话、截图和语音文本可能发往相应服务商并产生费用。

升级前备份必要数据，并从状态栏正常退出旧应用。用户数据仍在 `~/Library/Application Support/Nice People`，卸载不会自动删除。测试包不会预置维护者的数据，但运行时会沿用测试者自己已有的安装版配置。

## 本版范围

透明桌面角色、浮动聊天、状态栏控制、Live2D / 立绘与多形象、可配置 LLM / TTS、文字与语音、授权截图、陪伴模式、记忆与表单工作流。重新打包纳入当前应用版权、Live2D Core 许可和第三方声明，不改变用户角色配置或服务接入方式。

公开前还需进一步设备测试。真实麦克风噪声 / 回声、游戏内快捷键、多桌面 / 全屏、长期通话和不同服务商仍有待验收。视觉可能误读文本；不保证实时游戏策略或长影片理解。没有系统音频监听、VRM、云同步或自动更新。

## 本轮已验证

- 生产构建、66 项桌面单元测试、121 项服务测试通过。
- 对 DMG 只读挂载并复制到项目外的临时目录，签名校验、beta 版本、当前版权说明和无私人数据检查通过。
- 清除开发连接变量，在没有 Node / Python 开发路径的环境中实际启动内置服务，验证空白角色与聊天、访问鉴权、本地 Kokoro 合成、WebM 转换及 SenseVoice 转写。
- 实际应用启动，控制面板、悬浮角色窗口、聊天窗口及正常退出通过；测试副本与隔离数据已清理。没有录制麦克风、捕获用户屏幕或调用用户的收费模型。
- 包内语音资源清单的文件大小与 SHA-256 逐项核对通过；可扫描的应用及资源文本未发现凭据。大体积权重和原生二进制未作为文本完整扫描，不等于完整安全审计。

上述为本机测试，不是干净新设备、所有 macOS 版本或所有权限场景的验收。ASR 仍可能把“兆次元”转成同音字。
